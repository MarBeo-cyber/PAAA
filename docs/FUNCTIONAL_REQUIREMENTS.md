# Functional Requirements

| ID | Requirement |
|---|---|
| FR-01 | Build a personal baseline from controlled setup samples |
| FR-02 | Ingest physiological/motor samples from wearable sensors or simulated inputs |
| FR-03 | Extract tremor, smoothness, grip, voice, latency and stress proxy features |
| FR-04 | Detect deviation from personal baseline |
| FR-05 | Distinguish monitoring, biofeedback and review recommendation |
| FR-06 | Prevent diagnostic claims in output |
| FR-07 | Gate any stimulation plan behind explicit consent and safety policy |
| FR-08 | Preserve high-value deviation events using WAAA-style pruning |
| FR-09 | Provide a sensory, intuitive feedback interface |
