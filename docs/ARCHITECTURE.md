# PAAA Architecture

```text
Wearables / Sensors
        ↓
Sensing Layer
        ↓
Signal Normalization
        ↓
Personal Baseline Engine
        ↓
Deviation Detection Engine
        ↓
Biofeedback / Awareness Layer
        ↓
Autopoietic Memory
        ↓
Report Export
```

## Sensing Layer

Potential inputs:
- smartphone inertial data;
- smartwatch movement data;
- tremor-related micro-movements;
- voice markers;
- posture;
- gait rhythm;
- sleep and recovery data;
- optional consumer EEG or biosignal devices.

## Baseline Engine

PAAA compares the user with their own historical baseline, not with a generic population norm.

## Deviation Detection

Detects persistent deviations, not single isolated events.

## Biofeedback

Low-risk feedback:
- breathing guidance;
- motor exercises;
- awareness prompts;
- rhythm cues;
- relaxation prompts;
- structured journaling.

## Human Review

When persistent deviations are observed, PAAA can suggest professional evaluation and prepare a report.
