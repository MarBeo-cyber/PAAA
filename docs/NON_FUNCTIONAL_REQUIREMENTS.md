# Non-Functional Requirements

| ID | Requirement | Target |
|---|---|---|
| NFR-01 | Local-first processing | mandatory |
| NFR-02 | Baseline setup duration | 5-10 minutes MVP |
| NFR-03 | Monitoring loop latency | < 500 ms for feedback |
| NFR-04 | Stimulation disabled by default | mandatory |
| NFR-05 | Non-diagnostic language | mandatory |
| NFR-06 | Review recommendation audit | mandatory |
| NFR-07 | User consent for any sensitive signal | mandatory |
